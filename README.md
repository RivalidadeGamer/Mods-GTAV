# 🚗 GTAV Mods Collection
Bem-vindo ao meu repositório de modificações para Grand Theft Auto V. Aqui você encontrará scripts, texturas e melhorias de performance que desenvolvi ou personalizei para tornar Los Santos um lugar ainda mais interessante.
# 🛠️ O que há neste repositório?
•   Scripts Customizados: Melhorias na lógica do jogo e novas funcionalidades.

•   Melhorias Visuais: Presets de iluminação e texturas otimizadas.

•   Utilidades: Ferramentas para facilitar a instalação de outros mods.
# 🚀 Como Instalar
Importante:
Certifique-se de ter o Script Hook V e o OpenIV instalados antes de prosseguir.

1. Faça o download da pasta do mod desejado.
2. Siga as instruções específicas no arquivo README.md ou dentro da pasta de cada mod.
3. Geralmente, basta arrastar os arquivos para a pasta mods do seu diretório raiz do GTAV.
